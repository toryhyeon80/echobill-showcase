## UX 결정과 반영

1. **없어요 기억**: 같은 기기·같은 계정의 선택을 브라우저에 기억한다. 홈 재방문과 새로고침 뒤에도 반복 질문을 숨기고, 다른 계정에는 적용하지 않는다. 마이페이지의 외상 옮기기는 항상 남긴다. 브라우저 보관이 제한되면 기존 메모리 폴백을 따른다.
2. **어림 날짜**: 옮긴 외상 행은 `YYYY-MM-DD 무렵`으로 구분한다. 거래처 상세에서 가장 오래된 미수 행이 옮긴 외상일 때만 `약 N일 경과`로 표시한다. 일반 거래의 경과일은 그대로다. 홈 최근 기록의 옮긴 행에는 `날짜는 어림값`을 표시한다.
3. **공유 문구**: 거래처에 복사할 글에는 옮긴 행의 시스템 날짜와 내부 라벨 대신 `이전 외상`을 쓴다. 금액과 남은 금액은 서버 값을 유지한다.
4. **입력 설명**: `날짜와 경과일은 고른 시기를 기준으로 대략 계산해요`와 `남은 외상만 옮겨요`로 안내한다.
5. **집계 경과일**: 홈 전체·거래처 목록 API에는 가장 오래된 건이 옮긴 외상인지 나타내는 정보가 없다. 일반 거래까지 어림값으로 단정하지 않고 기존 서버 집계를 유지한다. 개별 상세와 옮기기 화면에서 어림 날짜를 설명한다. 서버 필드는 이번에 추가하지 않는다.
