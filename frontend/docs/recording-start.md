# 10/16 녹음 시작 알림

- 녹음 버튼의 사용자 동작에서 Web Audio를 준비한다. 마이크 연결이 500ms 넘을 때만 권한 안내를 표시하고, 듣는 화면과 짧은 음을 함께 시작한다. 실제 녹음과 30초 타이머는 음 종료·출력 여유 시간 뒤에 시작한다. 소리 미지원·차단은 화면 안내로 대체하며, 취소·이탈은 준비 중인 소리·마이크도 해제한다.
- 처음 3초는 거래처 이름 안내, 이후 상세 안내를 한 번 표시한다. 안내는 live region 밖에서 바뀌고 움직임 줄이기 설정에서는 페이드를 생략한다. 마이페이지의 녹음 시작 알림 설정은 이 기기에 소리·진동 여부만 저장한다.
- 실기기 확인은 별도: 아이폰·갤럭시 카톡에서 효과음·진동, 효과음의 녹음/전사 혼입 여부, 화면 잠금 후 권한 안내를 확인한다. 로컬 브라우저·합성 녹음 통과만으로 실기기 통과를 의미하지 않는다.
