## 이번 후속 수정

1. 합계 불일치 답이 반영돼도 선택 표시가 없던 문제: 선택 타일에 controlled 값과 aria-pressed를 연결했다. 답하기 전 원래 총액을 임의 선택으로 보여 주지 않는다. 버튼/음성 성공 뒤 명시적 확인은 그대로 필요하다.
2. 네트워크 오류 안내가 뒤로가기 확인창을 덮던 문제: RecordPage의 LeaveDraftDialog를 마지막 자식으로 이동했다. 로컬 실제 BrowserRouter에서 서버 중단→전송 실패→Android 뒤로가기→확인창 최상단→계속 확인 복귀를 재현했다.
3. 선행 RecordingOverlay 짧은 화면 하단 버튼·상단 스크롤 겹침 수정도 포함된 브랜치다.

금액 선택은 연결된 ClarificationCard를 사용하는 격리 UI에서 미선택/10000/20000 표시를 갤럭시로 확인했다. 실제 운영 음성 “일 만원” 성공 적용은 수정 전 내부 상태·활성 확인 버튼으로 확인했고, 새 음성 선택 표시는 API 어댑터 회귀 테스트로 확인했다. 로컬 가상 값 응답을 실제 STT 성공으로 세지 않는다.
