## 4. 판정 (A-4c 5장 기준 + D02 허용 폭) — 제안

- 기준: p21+후처리가 거래 정확도에서 Δ ≥ max(2건, 3회 편차)이고, 새로 틀린 건(c)이 0이면 v2.1을 10/5 Seed에 포함합니다.
- 결과: Δ = **+2**, 허용 폭 m = max(2, p0 편차 1, p21 편차 0) = **2** → **Δ ≥ m 충족**. c = **0** → 충족.
- **제안: v2.1을 10/5 Seed 측정 조건(`p21-on`)에 포함합니다.**

다만 다음 사항을 함께 판단해 주세요(최종 채택은 PM).
- 기준을 **경계값에서** 충족했습니다(Δ = m = 2). b 2건 중 013은 p0가 회차마다 맞고 틀리기를 반복해, p0 r1(40)과 비교하면 Δ는 +1입니다. 42건에서 2건 차이는 통계적으로 유의하지 않습니다(D02 §2 해석 제한).
- 건당 비용이 약 2.31배입니다. Seed 판정에서도 정확도가 "같으면 싼 쪽"(현재 프롬프트)이라는 PM 기준을 그대로 적용합니다.
- p21의 장점은 회차 편차가 0으로 안정적이라는 점입니다(p0는 1건, 013 회차 편차). 금액 Exact는 3회 모두 56/56입니다.

## 해석 제한

- **v2.1 규칙과 후처리 규칙은 Dev 오답(007·022·028·030·031·049)을 계기로 만들었으므로 Dev 수치는 낙관적이다.** 일반화는 10/5 Seed 측정과 최종 Golden(PM 관리)에서 확인한다.
- 추가 확인 적합성은 측정할 수 없습니다(BE 공통 검증 응답을 채점에 아직 연결하지 않음).
