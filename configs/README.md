# configs/

모델명·프롬프트·온도 등 AI 설정 파일 (CLAUDE.md §4 불변 규칙 13). 담당: AI.

**배포:** 레포 루트 `Dockerfile`이 `backend/`와 함께 이 폴더를 이미지의 `/app/configs`로 복사한다.
백엔드는 `backend/../configs/`로 찾으므로 두 폴더는 같은 부모 아래에 있어야 한다.
이 폴더를 옮기거나 지우면 운영에서 프롬프트를 못 찾아 모든 요청이 Rule 폴백된다.

## prompts/stt_prompt_ko.txt — STT 낱말 도움말

- **용도:** 음성 → 글자(STT) 요청에 `prompt`로 붙여, 장부 말투·단위 낱말을 더 잘 알아듣게 한다.
  `/parse-audio`와 음성 답(DL-31) 모두 같은 STT를 거치므로 둘 다 적용된다.
- **켜기:** env `STT_PROMPT_FILE`에 이 파일 경로. 운영(Railway 이미지)은 절대 경로 `/app/configs/prompts/stt_prompt_ko.txt`,
  로컬은 backend/에서 실행하므로 `../configs/prompts/stt_prompt_ko.txt`.
  비우면 끔(기본) — `prompt` 인자를 아예 넘기지 않아 켜기 전과 똑같은 요청. 상대 경로는 실행 위치(작업 디렉터리) 기준 — 운영 이미지는 `/app/backend`.
  경로를 넣었는데 파일이 없거나 못 읽으면 경고 로그 1회(경로만) 후 도움말 없이 전사(끈 것과 같은 요청).
- **길이:** whisper-1 다국어 토크나이저로 **145토큰** (한도 224, 넘으면 앞부분이 잘림). 고칠 때마다 다시 센다.
- **금지:** 평가 세트(Golden Dev·Test·음성 녹음 문장)의 거래처·품목 이름을 넣지 않는다 — 채점이 부풀려진다.
  장부 말투(외상·입금 등)와 단위 위주로 쓴다.
- **켜기 전:** 무음·잡음 합성 녹음 STT 확인(`eval/run_stt_noise.py`)으로 확인한다. 음성 답 판정 세트는 STT를 거치지 않는 글자 세트라 이 설정의 효과를 볼 수 없다.
- ⚠ 무음 확인 실패(gpt-4o-transcribe, 무음·잡음 21번 중 11번 '외상' 등 값 채움, 2026-10-15) — 켜지 말 것.

### 거래처 힌트 (`STT_COUNTERPARTY_HINTS`, 기본 꺼짐, PM 10/19)

- 켜면 `/parse-audio`에서 **그 사장님 본인의 확정 장부** 최근 거래처 이름(최대 `STT_COUNTERPARTY_HINT_LIMIT`곳, 120자까지)을
  도움말 끝에 `거래처: 가나상회, 다라식당` 줄로 덧붙인다. `STT_PROMPT_FILE`을 꺼 두어도 이 줄만 `prompt`로 간다.
  후보·거절·삭제 건과 다른 사장님 이름은 넣지 않는다. 음성 답(DL-31)에는 아직 붙이지 않는다.
- whisper-1은 도움말 끝 224토큰만 읽으므로 이름 줄이 길면 위 낱말 목록 앞부분이 잘린다 — 이름 줄을 120자로 끊는 이유.
- **켜기 전 무음 확인 필수:** 위 낱말 도움말처럼 무음·잡음 녹음에서 도움말 낱말이 결과에 끼어들 수 있다(10/15 '외상' 사례).
  거래처 이름이 끼어들면 없는 거래처가 후보에 채워진다 → 거래처 힌트를 넣은 채로 `eval/run_stt_noise.py`를 돌려 통과한 뒤에만 켠다.

## prompts/tts_instructions_ko.txt — 읽어 주기 말투 지시

- **용도:** `/api/v1/voice/speak`(읽어 주기)가 OpenAI 음성 합성에 `instructions`로 보낸다. 들을 때마다 톤이 달라지지 않게 짧게 둔다 (PM 11/2,
  PM 10/24 말투 지시에서 줄임). 실패 안내 파일(`stt-retry.mp3`, FE)은 PM 10/24 말투로 만든 그대로이므로 말투를 맞추려면 다시 만든다.
- **경로:** 기본으로 이 파일을 읽는다. 다른 파일을 쓰려면 env `TTS_INSTRUCTIONS_FILE`. 못 읽으면 모든 읽어 주기 호출이 504(화면은 글씨만).
